Wire-mesh sensor Wire-Mesh Sensors are extensively utilized for high-resolution imaging of multiphase flows, providing real-time measurements of phase distribution. A WMS comprises two perpendicular layers of parallel wires: transmitter wires in one plane and receiver wires in the other, forming a matrix of intersection points (in this study, a 16 ×16 wire arrangement, totaling 256 intersection points, was employed). A brief voltage pulse is sequentially applied to each transmitter wire, while receiver wires measure the resulting signals at intersections. The measured conductance at each intersection point reflects the local fluid composition; conductive phases like water exhibit high conductance, while non-conductive phases, such as gas, result in lower measured values. This spatially resolved data enables the reconstruction of detailed cross-sectional flow images at rates up to 10,000 frames per second, with spatial resolutions typically in the millimeter range [7]. To translate conductance measurements into meaningful physical param - eters such as void fraction, a normalization approach is necessary. Traditionally, void fraction α at a given intersection is computed using a linear approximation: α1σmix σcalC (1) where σmix is the conductivity of the two-phase flow and σcal is the conductance measured in a calibration procedure where the pipe is completely filled with water [8]. This linear method is straightforward but can introduce systematic errors, particularly in bubbly flow regimes, as it neglects complex electrical field interactions around small gas bubbles, often resulting in void fraction overestimation [9]. A more accurate approach utilizes Maxwell ’s equation to account for electrical field interactions [10], as first specifically applied to wire-mesh sensor signals by Prasser & Haefeli [11]: α1σmix σcal 10B5⋅σmix σcalC (2) This formulation significantly reduces systematic errors, especially for bubbles smaller than the sensor resolution, and has been experi - mentally validated using independent techniques such as X-ray tomog - raphy [12]. Thus, these methods provide reliable void fraction estimates crucial for accurate real-time multiphase flow analysis. 2.2. Dynamic histogram-based calibration Maintaining accurate calibration under continuously changing flow conditions, such as variations in temperature, pressure, or conductivity, is a significant challenge for multiphase flow measurement. Traditional WMS calibration typically requires dedicated calibration runs, where the sensor is fully immersed in a single-phase fluid [13]. These static procedures interrupt regular operations and limit flexibility. Traditional histogram-based calibration methods have previously been demon - strated and extensively documented [14,15]. To overcome this limita - tion, we introduce an adaptive histogram-based calibration method that utilizes real-time process data to continuously update calibration parameters. In the adaptive histogram-based approach, conductance measure - ments at each intersection point of the WMS grid are continuously monitored and statistically analyzed during normal sensor operation, generating localized histograms (Fig. 3). This adaptive method explicitly employs a sliding window averaging approach, continuously incorpo - rating recent sensor measurements into calibration histograms. Specif - ically, new histogram data are continuously added at each time step, and simultaneously, the oldest data points are removed using a FIFO (FirstIn-First-Out) buffer for each intersection point. By dynamically updating calibration parameters based on these sliding-window histograms, the method effectively compensates for variations in external conditions, ensuring sustained measurement accuracy and operational stability without interrupting the process. 2.3. FPGA systems excel at rapid data acquisition but are limited in adaptability for complex processing tasks [20,21]. CPUs offer flexibility and memory manage - ment but lack the parallel computation power needed for real-time analysis [22]. GPUs provide strong parallel capabilities but encounter data-transfer inefficiencies [23]. To overcome these challenges, this section proposes a hybrid computational architecture combining FPGA, CPU, and GPU compo - nents. Initially, a Xilinx Spartan-7 FPGA integrated into the Tomocon driver board rapidly interfaces with WMS hardware, performing raw data acquisition, noise filtering, and structured data serialization. Subsequently, the CPU handles data synchronization and memory management, preparing data for GPU-based analysis. The GPU then leverages its thousands of parallel cores to efficiently execute compu - tationally intensive operations, such as Fourier-based velocity estima - tion, cross-correlation analysis, and histogram-based calibration. By strategically assigning tasks according to each hardware compo - nent ’s strengths, the proposed FPGA-CPU-GPU system meets the realtime and computational demands essential for multiphase flow moni - toring. In the final processing stage, computed results including void fraction, gas-liquid interface velocity, and recalibrated sensor matrices are packaged into structured UDP packets [26] and transmitted to external systems for logging, visualization, or control. 4.1. Void fraction The void fraction calculation is implemented entirely on the GPU using a parallel architecture where each thread corresponds directly to an intersection point on the WMS grid. The allocation of GPU threads per block is precisely matched to the number of WMS intersection points, streamlining memory management and significantly improving the efficiency of memory coalescing [27]. Calibration constants, geometric correction factors, and scaling parameters required for the void fraction calculation are stored in GPU constant memory [27]. Although residing in global memory, the cached nature of constant memory ensures fast, simultaneous access by all GPU threads, effectively minimizing latency. This parallelized design allows threads from different blocks to concurrently retrieve calibration and geometric parameters based on their spatial coordinates, enabling simultaneous computation of local instantaneous void fractions across the entire sensor cross-section. Kernel execution and memory transactions occur asynchronously within GPU kernel streams, ensuring optimal computational throughput without impacting real-time performance. To handle continuous, long-duration measurements under dynami - cally changing conditions, the system periodically updates calibration parameters using rolling histogram statistics. These updates are performed asynchronously, enabling the system to adapt without interrupting data acquisition. Void fraction results are further refined through adaptive temporal averaging, wherein each spatial measurement point is processed with an averaging kernel over a configurable time window. This approach ensures compatibility with downstream instrumentation such as industrial PLCs, pressure sensors, or supervisory control systems operating at lower sampling rates (typically between 1 and 600 Hz) [28]. Notably, this temporal averaging step occurs after calibration, thus preserving spatial resolution while reducing response latency.From a systems design perspective, GPU-based implementation provides flexibility by allowing void fraction outputs at multiple data rates, ranging from full-resolution data suitable for high-speed diagnostics to filtered rates optimized for integration with Supervisory Control and Data Acquisition (SCADA) systems [29]. 4.2. Histogram Histogram computation is central to the adaptive calibration described in Section 2.2. The algorithm strategically distributes computation tasks between GPU and CPU, leveraging the strengths of each: the GPU efficiently generates histograms by categorizing and counting measurement values in real-time, while the CPU identifies dominant signal peaks within each histogram to update calibration parameters accordingly. Fig. 6illustrates the histogram computation procedure applied to Wire-Mesh Sensor (WMS) data. Each GPU thread independently assigns incoming sensor measurements, representing local void fractions, into 2¹¹ bins per spatial measurement point, thus covering the complete dynamic range of expected signal values, closely approximating purewater flow conditions. To enhance computational efficiency, bin counters are stored in GPU shared memory, significantly reducing read/write latency and optimizing resource utilization [30]. Within GPU architecture, threads in a warp concurrently execute identical instructions, preventing branch divergence and ensuring efficient parallel computation. Thread-specific data processing and accumulation of bin counts are managed using atomic addition operations stored in GPU global memory, thereby preserving data integrity even during concurrent updates from multiple threads. After GPU-based histogram generation, results are transferred to CPU host memory via GPU kernel streams for efficient synchronization. On the CPU side, an argmax algorithm identifies the most frequent voltage value (peak position) for each measurement point, referencing a calibration file that maps spatial positions across the WMS cross-section. This structured computational pipeline ensures accurate and responsive real-time recalibration, effectively handling dynamic process conditions in multiphase flow monitoring. Gas-liquid interface velocity Estimating gas-liquid interface velocity in multiphase flows involves determining the time delay between signals captured by two sequential sensors. The optimal velocity estimation method depends on the characteristics of the flow, as different algorithms perform optimally under specific conditions. FFT-based methods offer significant computational efficiency in velocity estimation due to rapid calculation of cross-correlation functions via frequency-domain transformations. In our implementation, FFT is exclusively utilized to efficiently compute the cross-correlation function, with the velocity determined by identifying the peak position within this function. This approach provides accurate velocity estimation in structured flow conditions, such as stratified and wavy annular flows, where distinct correlation peaks appear clearly. Howev - er, in chaotic or turbulent flow conditions, correlation peaks become less defined, potentially reducing the effectiveness of FFT-based velocity estimation methods [34]. Pearson correlation is more suitable for bubbly and dispersed flows, where velocity estimation is challenging due to the lack of distinct phase structures. GPU implementation of velocity estimation In the FFT-based method, measurement signals are transferred to GPU device memory and padded to the nearest power of two for optimized parallel computation [37,38]. The signals are then transformed into the frequency domain via FFT, and their spectra are multiplied element-wise, applying conjugation and shifting operations in parallel to compute the spectral cross-power density [39,40]. An inverse FFT transforms the multiplied spectra back into the time domain. The resulting cross-correlation function is then transferred back to the CPU, which identifies the peak position in the correlation, corresponding directly to the most probable time lag used for velocity estimation. The Pearson correlation method similarly uses GPU parallelism but directly computes statistical relationships in the time domain. Mean signal values are precomputed, enabling each GPU thread to indepen - dently calculate correlations across various time shifts. Intermediate covariance and variance calculations use shared memory to minimize global memory access latency [41]. Camera The high-speed camera system provides an independent reference for validating WMS velocity measurements. Unlike WMS, which estimates velocity based on electrical conductivity variations over time, optical methods allow for direct visualization of dispersed phase movement, enabling detection of bubble trajectories, phase boundaries, and flow structures. This external validation ensures that WMS-derived flow characteristics accurately reflect actual physical structures in the system. Consistency between WMS and optical measurements was verified by comparing velocity profiles obtained from WMS cross-correlation calculations and bubble displacement measurements derived from image processing techniques. This step validated the reliability of WMS results and helped refine signal processing techniques by identifying systematic errors. Beyond velocity validation, optical methods provided insights into spatial phase distribution. Correlating WMS void fraction maps with optical recordings enabled detection and correction of inconsistencies arising from conductivity-based signal distortions. Thus, high-speed camera validation served both as quantitative and qualitative verifica - tion, confirming the robustness of WMS-based real-time flow monitoring. The recording setup involved a high-speed camera operating at 480 frames per second, positioned perpendicular to the flow direction to minimize perspective distortions. Careful calibration was required to mitigate refractive distortions caused by variations in pipe material, liquid phase, and gas inclusions. Recorded footage was converted to grayscale to enhance contrast and reduce computational complexity. A region of interest was extracted from the central portion of the images to avoid optical distortions near pipe walls. Adaptive thresholding segmented bubbles from the background, followed by morphological processing steps to refine segmen - tation and remove artifacts. After segmentation, connected-component analysis identified individual bubbles and tracked their motion across frames (Fig. 7). The centroid of each bubble was used for nearest-neighbor tracking, ensuring consistent velocity estimation. Bubble velocities were computed from frame-to-frame displacement, using the precisely controlled frame rate. To ensure high-quality segmentation results for velocity estimation, rigorous filtering was applied. Bubbles were classified as well segmented if clearly isolated from the background by adaptive thresholding and morphological filtering. Centrally located bubbles were those fully contained within a predefined central image region, minimizing edge distortion effects. Bubbles with consistent trajectories exhibited stable paths across multiple frames without occlusion or irregular movements, ensuring accurate and reliable velocity measurements. Only bubbles meeting all these criteria contributed to the final velocity validation. A similar sensor-camera arrangement has previously been applied in the context of swirling flow separation systems, where the WMS was placed upstream and the camera downstream [19]. Discussion on computational performance and accuracy The performance evaluation presented in this study provides clear insights into the computational efficiency of the proposed hybrid FPGACPU-GPU architecture for real-time WMS data processing. Empirical analyses (Tables 2–4and Figs. 8–9) confirm that potential CPU-based methods, while suitable for small datasets, become computationally impractical for real-time analysis of larger datasets common in highfrequency multiphase measurements. Specifically, Table 2highlights the quadratic complexity of CPU-based Pearson correlation, demon - strating exponential increases in computation times as dataset sizes grow. Such limitations underscore the need for computationally efficient, parallelized approaches in high-speed industrial sensing applications. GPU-based implementations overcome these bottlenecks by exploiting thousands of parallel processing cores. Pearson correlation executed on GPU hardware exhibits near-linear computational complexity, significantly mitigating the exponential growth inherent to the CPU counterpart. Similarly, the FFT-based method, leveraging efficient frequency-domain transformations, further reduces computational latency, as illustrated explicitly in Figs. 8 and 9. The hybrid CPU-GPU architecture, strategically distributing computational tasks between units, consistently achieves the lowest latency and highest throughput, affirming its suitability for real-time applications. The selection between Pearson and FFT-based correlations signifi - cantly impacts measurement accuracy, as demonstrated in Fig. 9. Results indicate that FFT-based correlation provides robust velocity estimates in periodic or structured flow conditions (e.g., slug or annular flow), whereas Pearson correlation demonstrates superior accuracy in dispersed or bubbly flow conditions. Dynamically adapting the corre - lation method based on observed flow regimes embeds crucial engineering knowledge into the computational pipeline, enhancing velocity estimation robustness across diverse conditions.Validation through high-speed optical measurements further confirms the reliability of the hybrid computational approach. The observed relative errors between optical and WMS-derived velocities range from approximately 9 % to 10 %, demonstrating strong agreement supporting system reliability for multiphase flow analysis. The consideration of flow-specific characteristics reinforces the importance of domainspecific knowledge for accurate real-time flow measurement, particu - larly under transient or turbulent conditions. Additionally, integrating a new, second camera could validate upstream flow parameters and simultaneously capture downstream flow behaviors, providing additional robustness to the validation strategy. Beyond immediate applications in fluid separation, the modular structure and generalizability of the proposed hybrid computational framework are noteworthy. Although demonstrated specifically for inline fluid separation scenarios, adaptive histogram-based calibration and multimethod velocity estimation encode domain-specific insights readily transferable to other engineering domains. Potential broader applications include real-time diagnostics and preventive monitoring in steam-water turbines [43], chemical reactor performance control [44], environmental flow monitoring [45], and food-processing operations involving fermentation and carbonation [46]. This transferability emphasizes the relevance of the developed methods, indicating their potential to advance real-time knowledge-intensive monitoring and control across various engineering contexts. Future research could focus on further optimizing data transfer strategies between computational units (e.g., enhanced unified-memory approaches), employing advanced GPU hardware capabilities such as tensor cores for additional computational acceleration, and deeper integration into predictive-control or digital-twin environments, thereby further enhancing industrial responsiveness and operational intelligence. 6.Conclusions and future work This paper introduces a novel hybrid computational architecture integrating FPGA-based acquisition, CPU coordination, and GPUaccelerated computation for real-time multiphase flow monitoring using Wire-Mesh Sensors (WMS).
