Finally, Sect. 5 concludes the paper. 2 Proposed Design Methodology This section details the workflow for designing and imple - menting MobileNetV2, SqueezeNet, and ResNet18 on FPGA for image classification. The methodology includes CNN adaptation, model training, hardware-specific optimi - zations, and FPGA deployment, ensuring an optimal balance between accuracy, inference latency, and resource utiliza - tion. This study employs transfer learning, quantization, and pruning using the PyTorch framework within Xilinx Vitis AI, facilitating an efficient deployment pipeline tailored for real-time edge computing applications. Figure 1 illustrates the proposed workflow for deploying pretrained CNN models on FPGA. The process starts with data preprocessing and augmentation to improve model performance. During model training, pretrained models from PyTorch are fine-tuned on the CIFAR-10 dataset using transfer learning. These training steps are conducted within an Integrated Development Environment (IDE) such as Jupyter Notebook [ 21]. The trained models are then quan - tized to 8-bit integer precision, reducing computational complexity and enhancing hardware efficiency. Next, the models are compiled using the Vitis AI compiler, convert - ing them into FPGA-compatible binaries. These binaries are deployed to the FPGA’s Deep Learning Processing Unit (DPU), where real-time inference takes place. Finally, the models are tested on 10,000 CIFAR-10 images, and key per - formance metrics—including accuracy, inference latency, and resource utilization—are analyzed. This workflow simplifies FPGA deployment for DL mod - els, eliminating the need for low-level HDL or HLS coding while maintaining efficiency. By leveraging PyTorch in Vitis AI, this approach enhances model compatibility and ensures scalability for future AI applications on edge devices. 1 3 --- Página 3 --- Journal of Signal Processing Systems2.1 Software and Hardware Tools The models were developed and trained on a PC running Python 3.12.9 with the PyTorch framework. The system was equipped with 16 GB of RAM and an Intel i5-13400 F 2.50 GHz processor (referred to as CPU), which was used for data preprocessing and initial model development. Addi - tionally, a NVIDIA GeForce RTX 4060 (referred to as GPU) with CUDA 12.6 tools were utilized to accelerate model training and fine-tuning, providing significant computa - tional efficiency for DL tasks. For FPGA deployment, the Xilinx Vitis AI 2.5.0 tool - kit was employed to optimize and compile the models. The experiments were conducted using an Avnet Ultra96V2 evaluation board, which integrates a Zynq Ultra - Scale + MPSoC FPGA. This FPGA features a combination of programmable logic (PL) and ARM-based processing units (PS), making it well-suited for DL inference. The board is equipped with a DPU of DPUCZDX8G with a B1600 con - figuration, enabling efficient acceleration of CNN inference workloads. In our implementation, the DPU is responsible for executing all computational layers of the CNN models, including convolutional, pooling, and fully connected lay - ers. The PS is used for non-intensive tasks such as loading preprocessed input data, initiating inference, and collecting output results using the Python-based PYNQ framework. This setup ensures that core inference computation is per - formed entirely within the FPGA’s PL, leveraging the paral - lelism and low-latency characteristics of the DPU. 2.2 Dataset and Preprocessing This study utilizes the CIFAR-10 dataset, which con - sists of 60,000 color images (32 × 32 pixels) evenly dis - tributed across 10 classes. CIFAR-10 is widely used for benchmarking image classification models, particularly in resource-constrained environments such as FPGAs [ 22– 24]. The dataset is split into 50,000 images for training and 10,000 images for testing to evaluate model performance. To further improve model evaluation and prevent overfitting, the training set was further divided randomly into 40,000 images for training and 10,000 images for validation. To ensure compatibility with the pretrained CNN mod - els on ImageNet, all images were resized to 224 × 224 pixels, aligning with the input requirements of Mobile - NetV2, SqueezeNet, and ResNet18. Various data augmenta - tion techniques including random flips and rotations were applied to improve model generalization and robustness. Also, the images were normalized to a range of (-1,1), and processed in batches of 64. 2.3 CNN Models and Training Process This study employs three lightweight CNN architectures— MobileNetV2, SqueezeNet, and ResNet18—for image classification. We utilize the PyTorch framework, which supports BatchNormalization layers, allowing for improved convergence and stability during training. As illustrated in Fig. 2, the pretrained models were adapted to the CIFAR-10 dataset by replacing the fully con - nected layers of Classifier with custom layers tailored for the 10-class classification task. We did not freeze any layers during training process, allowing all layers to be updated during training to fine-tune the entire network. This strategy enhances model performance by adapting both low-level and high-level features to the new dataset. The models were trained for 10 epochs using the Stochas - tic Gradient Descent (SGD) optimizer with a learning rate of 0.01. To prevent overfitting, we implemented early stop - ping and learning rate reduction. Early stopping monitored validation loss and halted training if no improvement was observed for 5 epochs, ensuring computational efficiency. Unlike CPUs and GPUs, FPGAs enable hard - ware-aware model quantization and optimization, allowing models to achieve superior performance while minimizing resource utilization. These optimizations are particularly advantageous for edge AI applications such as autonomous vehicles and IoT, where energy efficiency and low-latency inference are critical.
