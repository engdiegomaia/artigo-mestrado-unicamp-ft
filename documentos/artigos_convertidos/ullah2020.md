NVIDIA Jetson platform provides promising performancein terms of energy efﬁciency, favorable accuracy, and throughput for running deep learning algorithms. In this paper, we present benchmarking of Jetson platforms (Nano, TX1, and Xavier) byevaluating its performance based on computationally expensive deep learning algorithms. Previously, most of the benchmark results were based on 2-D images with conventional deep learningmodels for image processing. However, the implementation ofmany other complex data types at Jetson platform has remained a challenge. We also showed the practical impact of optimizing the algorithm vs improving the hardware accelerations by deployinga diverse range of dense and intensive deep learning architectures at all three aforementioned Jetson platforms, to make a better comparison of performance. In this regard, we have used twoentirely different data-types, namely (i) ModelNet-40(Princeton3D point-cloud) data-set along with PointNet deep learning architecture for classiﬁcation of 3D point-cloud, and (ii) hyperspectralimages (HSI) datasets (KSC and Pavia) alongside stacked auto-encoders(SAE) to classify HSI correspondingly. This will broaden the scope of edge-devices to handle 3-D and HSI data whilst real-time classiﬁcation will be processed at edge-server underthe umbrella of edge-computing. The selection of (i) was made to exploit GPU heavily as the code uses TensorFlowgpu whereas (ii) was chosen to challenge the CPU cores of each platform as thecode is based on Theano and may suffer from under-utilizing theGPU cores. We have presented the detailed evaluation exclusively in term of performance indices as inference time, the maximum number of concurrent processes, resource utilization per processand efﬁciency. I.INTRODUCTION Over the years, applications of deep learning algorithms have grown drastically and remodeled the human lifestyle. Besides the development of complex and dense algorithms whichthrived for achieving higher accuracy, hardware accelerations have made it possible to accomplish the deployment of deeplearning algorithms so that the desired goals can be achieved.In this regard, several attempts have been made over the period to propose efﬁcient hardware(chipset) ranging from the era of revolution in DSPs, multi-core CPUs, GPUs, to dedicatedAI chipsets (Neural Processing Unit, AI Processing Unit)available in handheld and smart devices for efﬁcient executionof deep learning algorithms [1]. In addition, to deploy deep learning effectively, there are dedicated low-power and energyefﬁcient embedded system solutions offered in the market suchas Intel Movidius (Neural Compute Stick -I, -II) equippedwith neural compute engine, Raspberry Pi 3+ and NVIDIAJetson platforms like Nano, TX1, TX2, and Xavier equipped with high-speed GPUs. Among the mentioned stakeholders,the NVIDIA Jetson series takes a lead as it offers a wide range of developer kits available with a variety of speciﬁcations. There are many unique features associated with the NVIDIA Jetson series including energy efﬁciency (low power con-sumption), less weight, compact form-factor which enablesit to ﬁt inside any small robot or drone easily, its highperformance per watt and low-power GPU cores [2]. Based on the analysis presented in [3], Jetson provides higher peak performance than Raspberry Pi and Intel Movidius (NeuralCompute Stick). There are many applications of deep neuralnetworks (DNNs) trained on high-performance GPUs, whichare coded utilizing CUDA, and can be ported directly to the Jetson platform for Inference. Jetson series (Nano, TX1, TX2, Xavier) supports the cuDNN library which offers optimizedimplementation of fundamental kernels. However, to programa device like Raspberry Pi and others, deep learning kernelsneed to be developed using OpenCL since the cuDNN library is not supported by any device other than NVIDIA. These features attracted many developers to deploy deep learningalgorithms at Jetson platform like in edge devices for edge-computing and many other applications including autonomousdriving(TX-2 [4], TX-1 [5]), drones (TX-2 [6], [7] ), stress detection (TX-1 and TX-2 [8]), face detection (TX-2 [9]), and semantic segmentation(AGX-Xavier [10], [11]). II.R ELATED WORK Several attempts have been made in the past for benchmarking deep neural networks (DNNs) using multiple computing hardware based on various performance metrics. Famous benchmarking and efforts based on Jetson platforms are asfollows. Benchmarking DNNs using Tx1 board: . In [14], the author analyzed more than 40 DNNs based on multiple perfor-mance indices such as accuracy rate, model complexity (num-ber of parameters), memory usage, computational complexity(number of ﬂoating-point operations (FLOPs) ), and inferencetime. The primary focus of benchmarking was to select DNN that optimally ﬁt the available resource limitations. Similarly, another work presented the performance analysis of DNNsbased on accuracy, memory footprint, parameters, operationscount, power-budget and inference time [15]. All of DNNsused in [14] and [15] were based on 2-D image recognition trained on ImageNet-1K. The study conducted in [16] was different than previous two, as it was not focused more onevaluating the DNNs, rather its primary focus was to evaluatethe effectiveness of TX-1 for supporting real-time computervision workloads. DNNs implementation on Jetson (survey): In [2], the key features and challenges of NVIDIA Jetson series have beencompared with other computing platforms and has provided a comprehensive survey of work associated with optimizedimplementations of DNNs on Jetson platform. The author also presented a detailed review of Jetson embedded applicationsin the ﬁeld of medical, farming, robotics, drones, autonomousdriving, and many others. LPIR Challenge: LPIRC (Low-Power Image Recognition challenge) [17] is an annual competition initiated in 2015,to identify and acknowledge the best technologies based ona balance among power-budget, efﬁciency (short executiontime with low energy consumption) and accuracy (higherprecision) especially for computer vision applications (classifyand detect object in images). The vision system is evaluatedfor typically three categories namely (i) Model architecture,(ii) Inference Engine, and (iii) Hardware platform. Currently,there are three tracks for the competition including (i) Tﬂite Models on Mobile Phones, (ii) Caffe2 and TX-2, and (iii) Onsite with no restrictions. For the contest, a wider rangeof images data sets have been used so far, which includesImageNet, PASCAL, COCO (Common Objects in Contest),VOC, SUN (Scene UNderstanding), KITTI Vision Benchmark Suite, INRIA and Caltech Pedestrian datasets. NVIDIA AI City Challenge 2017, 2018: This competition was mainly focused on processing image and video datafor object detection, localization, and classiﬁcation which in turn provide solutions for trafﬁc and safety applications. The participants use to deploy their trained models at JetsonTX2 for inference [18]. NVIDIA AI city challenge was re-organized next year in 2018 that focused on processing trafﬁccamera video with three tracks including (i) speed estimation, (ii)anomaly detection and (iii) vehicle re-identiﬁcation [19]. Performance Comparison of Jetson Series: In [13], image, and video processing SDK have been developed forthe Jetson series (Nano, Tx1, TX2, and Xavier). Furthermore, the benchmarking results i.e GPU kernel times for 2K image processing have been evaluated which are related to cameraapplications: white balance, color correction, demosaic, jpegencoding and optional resize, etc. Jetson Nano, DL Inference Benchmarks: Benchmark results are available on the ofﬁcial website of NVIDIA [12],where a wide range of famous DNNs have been implementedon Jetson Nano for detection and localization of objects, image recognition, pose estimation, semantic segmentation, and video enhancement. In addition, the inference performanceof Jetson Nano has been compared with the latest computingplatforms like Raspberry Pi 3, Raspberry Pi 3+, Intel NeuralCompute Stick 2, and Google Edge TPU Dev Board using cor-responding frameworks like TensorFlow, PyTorch, Caffe, etc where Jetson Nano outperforms the aforementioned platforms. PointNet is a uni-ﬁed architecture that directly consumes 3D point-cloud andprovides class scores. Detailed architecture is shown in Fig.1. Stacked-autoencoders for HSI Classiﬁcation Hyper-spectral images (HSI) usually contain 100s of spectral bands and it is always challenging for deep learningarchitecture to handle a huge number of bands correspondingto pixels (in the spatial domain). The algorithm [23], we optedto implement at Jetson series for HSI classiﬁcation is com-posed of three parts such as (i) principal component analysis(PCA), (ii) deep learning framework (stacked-autoencoders),and (iii) logistic regression. For classifying spatial-dominatedfeatures, it takes all neighboring voxels (3d pixel) around aparticular pixel and PCA is then introduced to reduce thespectral dimensions whilst retaining the substantial data basedon the ﬁrst several principal components. Similarly, for the processing spectral domain, PCA is applied to spatial dimensions. These substantial shortlisted data are then provided tostacked auto-econders (SAE) separately which extract featuresacross corresponding domains (spatial and spectral). Finally,the classiﬁcation is implemented in the last layer of the neural network as logistic regression. The complete code for running this deep learning framework is available at GitHub [26]. Oneneeds to set up and install all dependencies and frameworksat each Jetson platform which is done in our experiment toachieve corresponding results.
